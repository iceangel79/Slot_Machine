# Tech-Stack

Date: 2026-10-24

## Status

Accepted

## Context

Rest of the tech stack, as per document "SW04 - Technologien - Auswahl und Empfehlungen.pdf"

## Options Considered

 * Option 1: Mostly using tech stack as proposed per Git-Template and SWEN Documents.
 * Option 2: Using different software, services and other tools not listed in the documents.

## Decision

Option 1 to keep it simple and make sure everything will be running smoothly. Furthermore we can introduce new tools and services later on if needed.

## Reasons

This approach is the most straightforward and least likely to cause problems.

## Consequences

* Easier: We can focus on the development of the application.
* Harder: We might miss out on some potential benefits of other tools and services.
* Risks: We might run into problems that we can't solve with the current toolset.
* Follow-up: The individual technologies are decided in decisions 0004 to 0010.
